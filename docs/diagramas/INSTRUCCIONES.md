# 🎨 Cómo Generar Diagramas Visuales - GUÍA PASO A PASO

**¡Buenas noticias! No necesitas instalar nada.**

---

## ⚡ Opción 1: MermaidLive (RECOMENDADO - 2 minutos)

### Paso 1: Abre Mermaid Live
```
Dirección: https://mermaid.live
O busca en Google: "mermaid live"
```

### Paso 2: Copia el código de un diagrama
Abre uno de estos archivos desde tu carpeta docs/diagramas/:
- `arquitectura_software.mmd`
- `diagrama_er.mmd`
- `flujo_guardar_estudiante.mmd`
- `flujo_programar_clase.mmd`
- `flujo_consultar_programacion.mmd`
- `casos_uso.mmd`

**Ejemplo:** Abre `arquitectura_software.mmd` en un editor de texto.

### Paso 3: Selecciona TODO y copia
```
Ctrl+A (selecciona todo)
Ctrl+C (copia)
```

### Paso 4: Pega en Mermaid Live
```
1. Abre https://mermaid.live
2. Haz click en el área de texto de la izquierda
3. Ctrl+A (borra todo)
4. Ctrl+V (pega el código)
5. ¡Verás el diagrama en la derecha en tiempo real!
```

### Paso 5: Descarga o Comparte
```
Opción A: Click "Download" → Descarga como PNG o SVG
Opción B: Click "Share" → Genera un link para compartir
Opción C: Click en el diagrama → "Copy SVG to Clipboard"
```

### ✨ Resultado:
Tendrás un diagrama visual bonito que puedes:
- Descargar como imagen
- Insertar en PowerPoint
- Compartir con tu profesor
- Incluir en documentación

## 🚀 Alternativas (Si Mermaid no funciona)

### Opción 2: Draw.io (Web)
```
1. Abre https://www.draw.io
2. Click "Create New Diagram"
3. Los archivos .mmd no se abren directo, pero puedes:
   - Dibujar manualmente los diagramas
   - O usar Mermaid para generar y luego ajustar
```

### Opción 3: Paste en GitHub
```
Si pones los archivos .mmd en GitHub:
GitHub renderiza Mermaid automáticamente
(No necesitas nada extra)
```

### Opción 4: PlantUML (Si quieres UML profesional)
```
Descarga: https://plantuml.com/es/download
O usa online: https://www.plantuml.com/plantuml/uml/
```

## 📞 Problemas Comunes

**P: "Mermaid Live no me muestra el diagrama"**
A: Verifica que pegaste TODO el código, incluyendo la primera línea

**P: "Quiero editar el diagrama después"**
A: Guarda el link que genera Mermaid Live, o descarga el .png y edita en PowerPoint

**P: "¿Cómo lo pongo en GitHub?"**
A: Sube los archivos .mmd → GitHub los renderiza automáticamente

**P: "¿Cuánto tiempo toma?"**
A: Máximo 10 minutos para los 6 diagramas
