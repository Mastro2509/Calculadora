# 📊 Diagramas Visuales - Generador de Diagramas

Este directorio contiene archivos para generar diagramas visuales de forma interactiva.

## 🎯 Opciones Disponibles

### Opción 1: Mermaid (Lo más fácil - Sin instalar nada)
Copia el contenido de los archivos `.mmd` en:
- https://mermaid.live (online)
- O usa directamente en Markdown con ` ```mmd `

### Opción 2: PlantUML
Descarga desde: https://plantuml.com/es/download
Instala y abre los archivos `.puml`

### Opción 3: Draw.io (Web)
Accede a: https://draw.io
Importa los archivos `.drawio`

### Opción 4: Graphviz
Descarga desde: https://graphviz.org/download/
Para diagramas rápidos en terminal

## ⚡ Inicio Rápido

### Paso 1: Abre Mermaid Online
```
https://mermaid.live
```

### Paso 2: Copia el contenido de cualquier archivo .mmd
```
Abre: arquitectura_software.mmd
Copia todo el contenido
```

### Paso 3: Pega en Mermaid Live
```
Pega en el editor izquierdo
¡Verás el diagrama en tiempo real!
```

### Paso 4: Descarga o Comparte
```
Click "Download" o "Share" en Mermaid Live
```
